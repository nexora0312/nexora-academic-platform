# Departments API

**Status: Planned; no department Route Handler is implemented.**

There is no implemented `/api/v1/departments` endpoint. Collection and item URLs, supported
methods, authentication and authorization requirements, filtering, request bodies, response
fields, and error statuses are **To Be Confirmed**.

The persisted department fields and their course relationship are documented in the
[database schema](../database/database-schema.md) and
[relationships](../database/relationships.md). A Prisma model is not an implemented REST endpoint.
