# Courses API

**Status: Planned; no course Route Handler is implemented.**

There is no implemented `/api/v1/courses` endpoint. Collection and item URLs, supported methods,
authentication and authorization requirements, filtering, request bodies, response fields, and
error statuses are **To Be Confirmed**.

The current persisted course fields and department relationship are documented in the
[database schema](../database/database-schema.md) and
[relationships](../database/relationships.md). A Prisma model is not an implemented REST endpoint.
