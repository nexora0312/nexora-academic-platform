# Sprint 01 architecture scope

Sprint 01 establishes the monorepo foundation:

- Independent Next.js frontend and backend workspaces.
- Versioned health API under `/api/v1`.
- Prisma MySQL foundation and seed data.
- Local Docker Compose services.
- API, architecture, database, development, and security documentation.
- Basic unit and integration test structure.

Academic, LMS, finance, full authentication UI, and all future SMS modules remain explicitly
outside the foundation implementation.
